# ADR 0003 — Agents Own Semantic Memory Management

## Status
Accepted

## Decision
The platform provides memory storage, retrieval, revision, and shared memory-management skills.

Each agent decides what its own memory means and what should be retained, merged, revised, or forgotten within policy.

## Why
A central memory janitor would need to understand every domain and would become an undesirable intelligence bottleneck.

## Consequences
Memory changes must be explicit, versioned, and attributable to the acting agent.
